# my_notes_web implementation rules

Read ../AGENTS.md, ../DESIGN-SYSTEM.md, and the task-specific guides indexed by ../README.md. This is the canonical application, renamed from test/. Keep implementation here.

- Node 24 is pinned in .node-version. Install with npm ci; preserve package-lock.json. npm run build is the required production check. npm run verify:library is the focused interaction check. Generated node_modules/, dist/, .astro/, and .sites-runtime/ are ignored.
- Content is src/content/lessons/{en,de,es}/. Match filenames across translations. Analysis lives under each locale’s analysis/ subfolder. Course metadata is required; lesson keys and orders are unique within a course. English is unprefixed. Use explicit registered chapter/sourceId metadata and page references checked against src/lib/sources.ts; drafts are excluded. Update chapter groups in src/lib/navigation.ts when publishing a lesson. Every published order must appear once.
- Register shared MDX views in src/components/mdx.ts. New content uses Interactive/VectorFigure, ordinary Markdown, Math, Note, Exercise, and Flow. Explorer/MatrixProduct remain compatibility names. Do not place arbitrary scripts, SVG HTML strings, or global styles in MDX.
- Interactive views live in src/components/interactive/. Pure state, SVG primitives, presets, and catalog live in src/lib/interactive/. Do not import the full index barrel into a browser controller if a focused module suffices. Validate new presets, add a gallery example, and test their mathematical boundary cases.
- Localize interface copy in src/lib/i18n.ts, vector controls/feedback in src/lib/interactive/vector-copy.ts, and scenario teaching overrides in each scenario's en/de/es text object. Never duplicate mathematical values into feedback strings; interpolate from the state.
- Use tokens.css, site.css, vector-lab.css, and shared KaTeX macros. Keep plot labels consistent with equations; color must not carry meaning alone. All user input stays local.
- Use src/lib/content.ts helpers for base-aware routes. Search must be tested in the production preview. /library/ is an English authoring reference, outside learner navigation/search; it is part of the static build.
- references/source/ is private and ignored. Preserve source provenance; never mark reviewed merely because a build succeeds. See ../docs/authoring.md before adding sources beyond the original worksheet.
- Update ../docs/representation-library.md and the catalog when changing a public component/preset contract. Update VERIFICATION.md after meaningful checks. Keep deployment/github-pages.yml inactive until publication is requested.

Do not add frameworks, services, a new visual system, or a general simulation engine for a single example without a concrete need. Two courses are registered: linear-algebra and analysis. Register new courses and sources explicitly; never clone this application. Read ../docs/source-ingestion.md for course-scoped routes, orders, prerequisites, and multiple-source provenance.
