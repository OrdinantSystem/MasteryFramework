### Un recorrido compacto por el material

Las secciones anteriores forman el recorrido principal por estos fundamentos. Empieza por <a href={lessonUrl("aussagen-und-aussageformen","es","analysis")+"#from-aussagen-und-aussageformen"}>enunciados y predicados</a>, y continúa con <a href={lessonUrl("aussagen-und-aussageformen","es","analysis")+"#from-definitions-assumptions-results"}>definiciones</a>, <a href={lessonUrl("zahlenmengen","es","analysis")+"#from-equality-and-equations"}>igualdad</a> y <a href={lessonUrl("zahlenmengen","es","analysis")+"#from-order-comparisons"}>comparaciones de orden</a>. Las <a href={lessonUrl("logische-verknuepfungen","es","analysis")+"#from-logische-verknuepfungen"}>conectivas lógicas</a>, la <a href={lessonUrl("logical-negation","es","analysis")+"#from-logical-negation"}>negación</a> y la <a href={lessonUrl("logische-verknuepfungen","es","analysis")+"#from-building-truth-tables"}>construcción de tablas de verdad</a> preparan las lecciones de <a href={lessonUrl("implikation-und-kontraposition","es","analysis")+"#from-material-implication-and-vacuity"}>implicación</a> y <a href={lessonUrl("biconditionals-and-equivalent-conditions","es","analysis")+"#from-biconditionals-and-equivalent-conditions"}>equivalencia</a>.

Para los cuantificadores, sigue con <a href={lessonUrl("universal-statements-and-domains","es","analysis")+"#from-universal-statements-and-domains"}>enunciados universales</a>, <a href={lessonUrl("universal-statements-and-domains","es","analysis")+"#from-bound-variables-and-scope"}>alcance</a>, <a href={lessonUrl("universal-statements-and-domains","es","analysis")+"#from-existence-and-witnesses"}>existencia</a>, <a href={lessonUrl("quantifier-order","es","analysis")+"#from-quantifier-order"}>orden y dependencia</a> y el <a href={lessonUrl("negating-nested-statements","es","analysis")+"#from-negating-quantified-statements-step-by-step"}>procedimiento de negación</a>. La <a href={lessonUrl("reading-sequence-convergence","es","analysis")+"#from-reading-sequence-convergence"}>aplicación a la convergencia</a> utiliza esas ideas después de introducir las <a href={lessonUrl("real-sequences","es","analysis")+"#from-real-sequences"}>sucesiones</a> y la <a href={lessonUrl("real-sequences","es","analysis")+"#from-absolute-value-and-distance"}>distancia absoluta</a>. La <a href={lessonUrl("negating-sequence-convergence","es","analysis")+"#from-negating-sequence-convergence"}>deducción de su negación</a> distingue fallar en un valor objetivo de <a href={lessonUrl("negating-sequence-convergence","es","analysis")+"#from-no-real-limit"}>no tener ningún límite real</a>.

Las lecciones originales de los pósteres y las hojas de ejercicios siguen sirviendo como aplicaciones. En particular, los ejercicios booleanos siguientes exigen la deducción algebraica indicada a partir de leyes numeradas; una explicación anterior mediante tablas de verdad no sustituye esa tarea.

1. Decide si la frase es un enunciado o aún tiene variables libres.
2. Precisa dominio y cuantificadores.
3. Identifica la estructura lógica y la dirección de la afirmación.
4. Elige un método de demostración y justifica cada paso.
5. En las deducciones booleanas, registra qué reglas ya están demostradas.
6. En circuitos, distingue una subexpresión escrita de una puerta física cuya salida puede reutilizarse.

### Preguntas para responder sin mirar

- ¿Por qué necesita una demostración propia la recíproca de una implicación verdadera?

<span id="from-analysis-grundlagen-ueberblick-un-problema-combinado"></span>

### Un problema combinado

Considera «para todo entero $n$, si $n^2$ es par, $n$ es divisible por 4». Identifica dominio e implicación. El lema de paridad solo da que $n$ es par, menos que la conclusión pedida. Con $n = 2$, $n^2 = 4$ es par pero 4 no divide a $n$. Ese caso refuta el enunciado universal. Un teorema pertinente no demuestra automáticamente todo lo solicitado.
