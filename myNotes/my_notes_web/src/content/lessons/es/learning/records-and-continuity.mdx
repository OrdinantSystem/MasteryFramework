## Tipos de registros

<LearningFigure kind="handoff" />

Una **nota de sesión** registra objetivo, fuentes, intentos exactos, pistas, resultados y próximo repaso. Una **ficha conceptual** contiene enunciado preciso, intuición con límites, ejemplo y no ejemplo, prueba y pregunta de transferencia. Un **registro de errores y repasos** sigue el primer paso inválido, corrección, nuevo intento autónomo y tarea de repaso. Enlaza tu propio trabajo para poder comprobar el resultado.

Lleva el último registro pertinente a una nueva conversación con el tutor. Si no hubo prueba diferida, escribe «no evaluado». Si la fecha es solo un plan, no sugieras que se creó un evento de calendario. Estas descargas Markdown vacías son plantillas locales; esta web no guarda registros personales.

## Una entrada útil

«Repasé lógica; entendí todo» aporta poco a la siguiente sesión. Una entrada útil dice: «Confundí recíproca y contraposición; usé H2; corregí n = 6; pendiente un problema nuevo sin ayuda». Identifica avance y evaluación pendiente. Conserva también pregunta e intento originales para que otro tutor pueda valorar las evidencias.
