## Aclara las funciones

Tú eliges el objetivo, intentas el trabajo y señalas la incertidumbre. El tutor ayuda a ordenar tareas, ajustar dificultad y dar comentarios. Las fuentes del curso determinan sus convenciones. Una IA no debe inventar citas, recordar sesiones no proporcionadas ni llamar autónomo al trabajo con pistas. Esta web explica el proceso; no conecta con un tutor de IA ni recoge respuestas.

## Una instrucción inicial portable

```text
Tema: [tema]
Objetivo: [lo que quiero hacer con autonomía]
Nivel y tiempo: [nivel; tiempo disponible]
Fuentes y lagunas conocidas: [fuentes; lagunas o desconocidas]

Empieza con un diagnóstico breve sin ayuda. Haz una pregunta significativa cada vez. Déjame intentar antes de mostrar la solución, salvo que haya que enseñar una base previa. Da la pista mínima útil y registra el nivel H0–H5 más alto. Contrasta las afirmaciones con mis fuentes, señala la incertidumbre y termina con evidencias autónomas, una laguna abierta y una tarea de repaso diferido.
```

## Pide una acción útil

Usa MAP para un mapa parcial, PROOF para revisar tu argumento, HINT 1 para una pregunta estratégica, TRANSFER para un problema nuevo sin pistas, RECALL para una prueba sin apuntes y WRAP para el resumen de continuidad. Son convenciones para tu conversación externa con el tutor, no botones ni servicios de esta página. Contrasta con la fuente la definición o el paso discutido antes de reutilizar un juicio de la IA.
