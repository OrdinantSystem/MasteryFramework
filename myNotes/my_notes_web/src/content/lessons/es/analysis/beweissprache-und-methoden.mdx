## Reconoce la función de cada frase

Una definición fija un significado. Un axioma se acepta como punto de partida. Una hipótesis se asume para el argumento actual. Una conjetura espera demostración. Un teorema o proposición es una afirmación demostrada; un lema apoya otra demostración y un corolario se deduce de un resultado establecido. Los nombres describen funciones, no grados de verdad.

## Elige un método

- Demostración directa: partir de las hipótesis y deducir la conclusión.
- Contraposición: demostrar que una conclusión falsa obliga a una premisa falsa.
- Contradicción: asumir la negación del objetivo y deducir una imposibilidad.
- Contraejemplo: refutar una afirmación universal con un caso permitido.
- Inducción: demostrar un caso inicial y un paso de n a n + 1; un método para una lección posterior, no un sustituto de esos pasos.

## Un pequeño proceso

Escribe la afirmación exacta y el dominio. Desarrolla las definiciones. Elige un método. Justifica cada transición. Indica qué se ha demostrado. Para ∃n ∈ ℕ: n² = 9 basta el testigo n = 3. Para ∀n ∈ ℕ: n² > n basta el contraejemplo n = 1. Ninguna tarea requiere una deducción larga. No uses la propia afirmación para justificar un paso intermedio: sería circular.

## De una definición a una prueba

Para probar que la suma de dos enteros pares es par, introduce testigos distintos: a = 2r y b = 2s. Entonces a + b = 2(r + s), con r + s entero. La expresión final coincide con la definición de par. Escribir a = 2r y b = 2r supondría por accidente entradas iguales. Hasta una prueba breve necesita el dominio y explicar por qué la última línea resuelve la afirmación.
