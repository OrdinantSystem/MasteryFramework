## La afirmación

<Math tex="\forall n\in\mathbb Z:\quad 2\mid n\iff2\mid n^2" display />

«Par» significa n = 2k para un entero k. «Impar» significa n = 2k + 1. Una equivalencia exige ambas direcciones; una sola implicación deja la mitad sin demostrar.

## Ida: usa la definición

<Math tex="n=2k\quad\Longrightarrow\quad n^2=4k^2=2(2k^2)" display />

El término entre paréntesis es entero, por lo que el cuadrado es par.

## Vuelta: usa contraposición

<Math tex="n=2k+1\quad\Longrightarrow\quad n^2=4k^2+4k+1=2(2k^2+2k)+1" display />

Un entero impar tiene cuadrado impar. Esto demuestra la contraposición de «si el cuadrado es par, el entero es par». También vale para enteros negativos y cero; no restrinjas tácitamente el dominio a los positivos.

## ¿Por qué usar contraposición aquí?

Partir de n² = 2k no escribe inmediatamente n como el doble de un entero: extraer la raíz deja abierta la pregunta que debemos resolver. La imparidad tiene una forma más útil, n = 2k + 1. Al elevar al cuadrado obtenemos una parte par más 1; un impar no puede tener cuadrado par. Así se excluye el obstáculo a la vuelta. k puede ser negativo; no se usó positividad.

## Práctica

Usa una representación de la definición e identifica el entero que queda entre paréntesis.

<Exercise question="Demuestra que el producto de dos enteros impares es impar.">

Escribe a = 2r + 1 y b = 2s + 1. Su producto es 4rs + 2r + 2s + 1 = 2(2rs + r + s) + 1. El paréntesis es entero y proporciona la forma impar.

</Exercise>
