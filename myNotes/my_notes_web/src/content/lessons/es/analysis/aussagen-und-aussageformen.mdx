## Un enunciado puede ser falso

Un enunciado tiene un valor de verdad definido: verdadero (1) o falso (0). No hace falta que lo conozcamos. Tanto «2 + 3 = 5» como «2 + 3 = 6» son enunciados; solo el primero es verdadero.

## Una variable libre deja una pregunta abierta

P(x): x + 3 = 10 es un predicado. Su verdad depende de x. Indicar x ∈ ℕ restringe el dominio, pero no liga x. Sustituir x = 7 produce un enunciado verdadero; x = 2, uno falso. También puede ligar la variable un cuantificador.

## Comprueba la clasificación

Una pregunta o una orden no es un enunciado. «Esta frase es falsa» no admite un valor de verdad clásico consistente: es una paradoja, no un ejemplo corriente de enunciado falso. Clasifica una ecuación antes de intentar demostrarla.
