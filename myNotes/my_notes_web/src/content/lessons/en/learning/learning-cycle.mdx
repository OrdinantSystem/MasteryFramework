## Learning objectives

“Study linear maps” is a topic. “Decide whether an unfamiliar map is linear and justify my answer” is a goal you can test. Keep the topic small enough to practise, and use your course notes to fix the definitions and conventions.

## The four methods

<LearningFigure kind="methods" />

You do not need every method in every session. A missing definition may call for retrieval; a wrong method choice calls for comparison; an unclear argument calls for explanation and feedback. Choose the work that addresses the actual gap.

## The learning cycle

<ProcessDiagram preset="cycle" id="learning-cycle-diagram" />

This is our synthesis of the supplied material. It is a working protocol to adjust with evidence, not a promise of effortless learning or a scientifically optimal sequence. Immediate success is a useful beginning; a new task after a delay tells you more about what remains available.

## Example: linearity

Suppose you can repeat the definition of a linear map but classify 2x + 3 as linear. A longer reading session may leave that error untouched. First compare the claim with the zero-input condition. Then explain why translation breaks linearity. Finally classify a new map without a hint. Mapping identifies the relationships, explanation tests the reasoning, mixed tasks test the choice, and a delayed problem checks retention. The same difficulty determines which method is useful at each point.
