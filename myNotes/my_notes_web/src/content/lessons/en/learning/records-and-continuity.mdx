## Types of record

<LearningFigure kind="handoff" />

A **session note** records the goal, sources, exact attempts, hints, results, and next review. A **concept card** holds a precise statement, intuition with limits, an example and non-example, proof evidence, and a transfer question. An **error/review log** tracks the first invalid step, repair, new independent attempt, and review task. Keep links to your own work so the result can be checked.

Carry the latest relevant record into a new tutor session. If no delayed test was done, write “not assessed”. If the next date is only a plan, do not imply a calendar event was created. These blank Markdown downloads are local templates; this site does not save personal learning records.

## A useful record entry

“Reviewed logic; understood everything” gives the next session little to work with. A useful entry says: “Confused converse and contrapositive; used H2; corrected the n = 6 example; new unassisted problem still pending.” That record identifies both progress and unfinished assessment. Keep the original question and answer alongside it so another tutor can judge the evidence.
