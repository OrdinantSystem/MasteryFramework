## A matrix connects input and output

The expressions $u=3x+2y$, $v=7x-5y$, and $w=-x+11y$ use the same two inputs. Their coefficients form a matrix with three rows and two columns.

<Flow />

We write $b=Ax$. The matrix $A$ represents a map from $\mathbb R^2$ to $\mathbb R^3$: two coordinates become three. The number of components can change.

## Read the rows to calculate

Multiply each row component by the corresponding input component, then add. For the input $(x,y)=(1,2)$, the example gives:

<Math tex="\begin{pmatrix}3&2\\7&-5\\-1&11\end{pmatrix}\binom12=\begin{pmatrix}3\cdot1+2\cdot2\\7\cdot1-5\cdot2\\-1\cdot1+11\cdot2\end{pmatrix}=\begin{pmatrix}7\\-3\\21\end{pmatrix}" display />

This is the practical calculation rule. The column perspective explains its geometry.

## Read the columns to understand

The first column is the image of the first standard basis vector; the second is the image of the second. Every input is a linear combination of those basis vectors, so its output is the same combination of the matrix columns:

<Math tex="\colA{A}\binom{x}{y}=x\underbrace{\begin{pmatrix}3\\7\\-1\end{pmatrix}}_{a_1}+y\underbrace{\begin{pmatrix}2\\-5\\11\end{pmatrix}}_{a_2}" display />

The following **additional 2D example** also has two-dimensional outputs, so you can see the addition directly. Change the coefficients and watch the sum move.

<Interactive kind="vectors" preset="linear-combination" id="vector-lab-combination" />

Each column has a fixed direction. The input controls how much it is stretched, shortened, or reversed. The two contributions are then added.

<Note title="The connection">Rows and columns organize the same sum in different ways: by output coordinates or by contributions from each input.</Note>

## The general form

For $A\in\mathbb R^{m\times n}$ with columns $a_1,\ldots,a_n$ and input $x\in\mathbb R^n$:

<Math tex="Ax=x_1a_1+\cdots+x_na_n=\sum_{k=1}^{n}x_ka_k\in\mathbb R^m" display />

<Exercise question="Which input produces exactly the second column of A?">
The second standard basis vector $e_2$: its second component is $1$ and all others are $0$. Thus $Ae_2=a_2$. In the 2D explorer, set $a=0$ and $b=1$.
</Exercise>
