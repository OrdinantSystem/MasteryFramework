## An inclusion picture

<NumberDomains />

Each inner set is contained in the next outer set. The examples placed outside an inner box belong to the surrounding set but not that inner set. Irrational real numbers lie inside ℝ and outside ℚ. Non-real complex numbers lie outside ℝ.

## What makes a number rational?

<Math tex="\mathbb Q=\left\{\frac pq:p\in\mathbb Z,\ q\in\mathbb Z\setminus\{0\}\right\}" display />

A rational number has an integer numerator and a nonzero integer denominator. Its decimal expansion terminates or eventually repeats. √2, √3, and π are irrational. The imaginary unit satisfies i² = −1. The convention about whether 0 belongs to ℕ varies between courses; here it does not.

## Classifying a number

Start with the smallest set that contains the number. −3 belongs to ℤ, hence also to ℚ, ℝ, and ℂ; write −3/1 to see why it is rational. The number 0.125 equals 1/8, so it lies in ℚ but not ℤ. √2 lies in ℝ outside ℚ. Inclusion is one-way: every integer is rational, but 1/2 shows that not every rational is an integer. The boxes describe membership, not how large a number is.

## Practice

Use the inclusion picture to justify the smallest applicable set, rather than listing memberships from memory.

<Exercise question="Where do −5/2 and √9 belong?">

−5/2 is rational but not an integer. √9 = 3 is natural under the convention used here, so it also belongs to all the larger sets. A radical symbol alone does not mean a number is irrational.

</Exercise>
