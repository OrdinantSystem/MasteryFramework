## A statement can be false

A statement has a definite truth value: true (1) or false (0). We do not have to know which one it is. Both “2 + 3 = 5” and “2 + 3 = 6” are statements; only the first is true.

## An open variable leaves a question

P(x): x + 3 = 10 is a predicate. Its truth depends on x. Specifying x ∈ ℕ restricts the domain but does not bind x. Substitute x = 7 to obtain a true statement, or x = 2 to obtain a false one. A quantifier can bind the variable instead.

## Check your classification

A question or command is not a statement. The sentence “This sentence is false” cannot receive a consistent classical truth value; it is a paradox, not an ordinary example of a false statement. Try classifying an equation before attempting to prove it.
