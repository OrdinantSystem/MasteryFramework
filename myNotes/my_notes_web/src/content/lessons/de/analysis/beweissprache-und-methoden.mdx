## Die Rolle jedes Satzes kennen

Eine Definition legt eine Bedeutung fest. Ein Axiom wird als Ausgangspunkt angenommen. Eine Hypothese wird für das aktuelle Argument vorausgesetzt. Eine Vermutung wartet auf einen Beweis. Satz oder Proposition bezeichnen bewiesene Behauptungen; ein Lemma hilft einem weiteren Beweis, ein Korollar folgt aus einem bekannten Ergebnis. Diese Namen beschreiben Rollen, keine unterschiedlichen Wahrheitsgrade.

## Eine Methode wählen

- Direkter Beweis: Aus den Voraussetzungen die Folgerung herleiten.
- Kontraposition: Aus der falschen Folgerung die falsche Voraussetzung ableiten.
- Widerspruch: Die Negation des Ziels annehmen und eine Unmöglichkeit herleiten.
- Gegenbeispiel: Eine Allaussage mit einem erlaubten Fall widerlegen.
- Induktion: Anfang und Schritt von n zu n + 1 beweisen; eine Methode für eine spätere Lektion, kein Ersatz für einen dieser Schritte.

## Ein kleiner Arbeitsablauf

Formuliere Behauptung und Bereich genau. Löse Definitionen auf. Wähle eine Methode. Begründe jeden Übergang. Halte fest, was bewiesen ist. Für ∃n ∈ ℕ: n² = 9 genügt n = 3 als Zeuge. Für ∀n ∈ ℕ: n² > n genügt n = 1 als Gegenbeispiel. Beides braucht keine lange Rechnung. Nutze die Behauptung nicht selbst zur Begründung eines Zwischenschritts: Das wäre ein Zirkelschluss.

## Von einer Definition zum Beweis

Für die Summe zweier gerader Zahlen nutze getrennte Zeugen: a = 2r und b = 2s. Dann ist a + b = 2(r + s), wobei r + s ganzzahlig ist. Das entspricht genau der Definition von Geradheit. a = 2r und b = 2r würde versehentlich gleiche Eingaben voraussetzen. Auch ein kurzer Beweis braucht den Bereich und die Erklärung, warum die letzte Zeile das Ziel erreicht.
