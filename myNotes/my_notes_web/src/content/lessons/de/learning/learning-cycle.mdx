## Mit einer konkreten Fähigkeit beginnen

„Lineare Abbildungen lernen“ ist ein Thema. „Bei einer unbekannten Abbildung entscheiden und begründen, ob sie linear ist“ ist ein überprüfbares Ziel. Begrenze das Thema so, dass du üben kannst. Die Kursunterlagen bestimmen Definitionen und Konventionen.

## Vier Methoden, vier Aufgaben

<LearningFigure kind="methods" />

Du brauchst nicht jede Methode in jeder Sitzung. Eine fehlende Definition verlangt vielleicht Abruftraining, eine falsche Methodenwahl einen Vergleich, eine unklare Begründung eine Erklärung mit Rückmeldung. Wähle die Arbeit passend zur tatsächlichen Lücke.
