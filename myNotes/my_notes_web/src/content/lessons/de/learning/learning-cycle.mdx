## Lernziele

„Lineare Abbildungen lernen“ ist ein Thema. „Bei einer unbekannten Abbildung entscheiden und begründen, ob sie linear ist“ ist ein überprüfbares Ziel. Begrenze das Thema so, dass du üben kannst. Die Kursunterlagen bestimmen Definitionen und Konventionen.

## Die vier Methoden

<LearningFigure kind="methods" />

Du brauchst nicht jede Methode in jeder Sitzung. Eine fehlende Definition verlangt vielleicht Abruftraining, eine falsche Methodenwahl einen Vergleich, eine unklare Begründung eine Erklärung mit Rückmeldung. Wähle die Arbeit passend zur tatsächlichen Lücke.

## Der Lernkreislauf

<ProcessDiagram preset="cycle" id="learning-cycle-diagram" />

Das ist unsere Zusammenführung des vorliegenden Materials. Sie ist ein anhand von Ergebnissen anpassbarer Arbeitsablauf, kein Versprechen mühelosen Lernens und keine wissenschaftlich optimale Reihenfolge. Unmittelbarer Erfolg ist ein Anfang; eine neue Aufgabe nach einer Pause zeigt mehr darüber, was verfügbar bleibt.

## Beispiel: Linearität

Angenommen, du kennst die Definition einer linearen Abbildung, ordnest aber 2x + 3 als linear ein. Längeres Lesen kann diesen Fehler unverändert lassen. Prüfe zuerst die Nullbedingung, erkläre dann die Wirkung der Verschiebung und ordne schließlich eine neue Abbildung ohne Hinweis ein. Das Netz ordnet Beziehungen, die Erklärung prüft die Begründung, gemischte Aufgaben die Auswahl und eine spätere Aufgabe den Abruf. Die konkrete Schwierigkeit bestimmt jeweils die hilfreiche Methode.
