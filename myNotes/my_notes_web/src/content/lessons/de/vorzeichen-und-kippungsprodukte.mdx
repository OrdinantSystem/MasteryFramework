## Die Vorzeichen auf der Diagonalen multiplizieren

<Math tex="D=\operatorname{diag}(d_1,\ldots,d_n),\quad d_i\in\{-1,1\},\qquad\det D=\prod_{i=1}^{n}d_i=(-1)^k." display />

Dabei zählt $n$ alle Diagonaleinträge, $k$ hingegen nur die negativen. Das Produktzeichen bedeutet $d_1d_2\cdots d_n$. Eine gerade Anzahl von Minuszeichen ergibt $+1$, eine ungerade Anzahl $-1$.

<Math tex="\operatorname{diag}(-1,1,-1,1):\quad n=4,\quad k=2,\quad\det D=(-1)\cdot1\cdot(-1)\cdot1=1." display />

## Warum eine ungerade Anzahl unmöglich ist

Jede elementare Kippung hat Determinante 1, ebenso jedes endliche Kippungsprodukt. Eine Vorzeichenmatrix mit Determinante $-1$ kann daher kein solches Produkt sein. Das ist ein Ausschlussargument, noch keine Konstruktion.

<Math tex="\det(T_1\cdots T_r)=\prod_{j=1}^{r}\det T_j=1\ne-1." display />

## Zwei Vorzeichenwechsel konstruieren

<Math tex="H=\begin{pmatrix}1&-1\\0&1\end{pmatrix},\qquad V=\begin{pmatrix}1&0\\1&1\end{pmatrix},\qquad HVH=\begin{pmatrix}0&-1\\1&0\end{pmatrix}=J." display />

<Flow nodes={[{"label": "Kippungen", "tex": "HVH", "detail": "Drei zugelassene Faktoren"}, {"label": "Vierteldrehung", "tex": "J", "detail": "Drehung um 90°"}, {"label": "Halbe Drehung", "tex": "(HVH)^2=-I_2", "detail": "Beide Vorzeichen wechseln"}]} caption={"Die Wirkung beginnt beim rechten Faktor. Das Produkt steht in algebraischer Reihenfolge."} />

Für Koordinaten $i\ne j$ verwendet man $H_{ij}=I_n-E_{ij}$ und $V_{ji}=I_n+E_{ji}$. Derselbe zweidimensionale Block funktioniert in einer größeren Matrix und lässt die anderen Koordinaten unverändert.

<Math tex="(H_{13}V_{31}H_{13})^2=\operatorname{diag}(-1,1,-1,1)\quad(n=4)." display />

Paare die negativen Positionen und verwende für jedes Paar eine Konstruktion. Damit ist jede Vorzeichenmatrix mit gerader Anzahl negativer Einträge durch diese Kippungen erzeugbar. Ohne negative Einträge liefert das leere Produkt die Einheitsmatrix.

<Note title={"Die hier verwendete Konvention"}>
In diesen Notizen bedeutet „unimodular“: durch die zugelassenen Kippungen erzeugbar, also kippungsäquivalent zur Einheitsmatrix. Diese Konvention bleibt ausdrücklich festgelegt. Determinante 1 ist notwendig; die obige Konstruktion zeigt die Hinlänglichkeit für diese Vorzeichenmatrizen.
</Note>

<Math tex="D=\operatorname{diag}(1,-1,1),\qquad\det D=-1." display />

<Math tex="U=\colA{\begin{pmatrix}1&2\\0&1\end{pmatrix}}\colB{\begin{pmatrix}1&0\\3&1\end{pmatrix}}=\colResult{\begin{pmatrix}7&2\\3&1\end{pmatrix}},\qquad\det U=1." display />

<Exercise question="Kann diag($-1$,$-1$,$-1$,1) ein Kippungsprodukt sein?">
Nein. Drei negative Einträge ergeben Determinante $-1$. Die Matrix ist trotzdem eine invertierbare Involution.
</Exercise>
