# Analysis I first-semester teaching refinement

Jean authorized implementation on 4 November 2026 after the EGM concept review. The first batch changes the overview and predicates, quantifier order and convergence, with small prerequisite/support changes to number systems, sequences and failure of convergence. It preserves twenty canonical lessons, six sections, the approved shell and EN/DE. Optional Boolean material remains intact.

## Teaching route

- The overview opens with scope and a path through the foundations to sequence limits. Original review tasks remain; the parity problem permits an attempt before its answer. A core sequence synthesis links to proof and failure lessons.
- Predicates begin with rule, allowed input and evaluated statement. Definitions precede the later visible quantifier/proof connection. All formal tasks and anchors remain. Independent practice uses a changed integer rule and a constant-truth condition.
- Quantifier order starts with the complete key model, then connects to the retained general reading procedure. The activity has one initial prediction and retains the key-removal challenge. A complete numerical relation tests separate/shared witnesses. Optional banks name their purpose.
- Sequence introductions show positions, values, repetition and a tail. Convergence connects that picture to its existing definition and justified proof. A changed eventual-constant proof is core; reciprocal threshold construction and written 2/n transfer remain optional with additional accepted background.
- Failure of convergence adds an arbitrary-target proof for the alternating sequence, choosing suitable parity at N or N+1. All six original negation stages remain.

New examples are authored additions. Core questions stay visible; solutions and optional banks use disclosures. Independent AI semantic review does not change mathematical/translation reviewStatus or demonstrate faster learning. Student attempts and delayed transfer remain untested.
