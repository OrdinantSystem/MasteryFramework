## Problem and intended behavior

A university learner new to study methods should be able to enter this course without already knowing convergence or linear maps. They should see how retrieval differs from spacing and mixing, try a study decision, and check the existing proof-session tasks against full reference answers. The existing course already covers feedback, attribution, assistance, evidence and most methods in depth. Preserve that work.

The first batch adds a familiar entry and local links, a beginner bridge for Bloom's mathematical lens, a linked retrieval example with an unfamiliar decision task, and the missing reference arguments for existing session/proof tasks.
