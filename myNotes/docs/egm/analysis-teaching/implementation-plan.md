## Focused presentations

Keep pure mathematical models unchanged. Extend the existing analysisScene and AnalysisLab with a closed optional presentation value: full (default), input (candidates/equation only), witnesses (quantifiers/keys only), terms (sequence/device only), tail (sequence/reciprocal only). Validate combinations at initialization. Unsupported combinations throw. Full preserves existing behavior.

Each focused view owns a coherent localized title, prompt, caption, readouts and available controls. Input has x/domain/reset and membership/evaluated truth, without quantified counts. Witnesses has the existing complete relation controls and its two positive claims; surrounding prose and component prompt give the same first action. Terms has N/reset and positions/values without tolerance logic; tail has epsilon/N/reset, fixed reciprocal rule and zero target. Terms/tail draw the plot before controls. Initial server-rendered content and browser updates call the same scene function with the presentation. Store the presentation in data attributes; reset restores the same fixed configuration. Keep input elements stable through redraw, numeric/keyboard alternatives and bounded validation. No arbitrary configuration flags, copied engines or per-lesson controllers.
