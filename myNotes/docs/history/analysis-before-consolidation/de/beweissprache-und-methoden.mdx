## Die Rolle jedes Satzes kennen

Eine Definition legt eine Bedeutung fest. Ein Axiom wird als Ausgangspunkt angenommen. Eine Hypothese wird für das aktuelle Argument vorausgesetzt. Eine Vermutung wartet auf einen Beweis. Satz oder Proposition bezeichnen bewiesene Behauptungen; ein Lemma hilft einem weiteren Beweis, ein Korollar folgt aus einem bekannten Ergebnis. Diese Namen beschreiben Rollen, keine unterschiedlichen Wahrheitsgrade.

## Eine Methode wählen

- Direkter Beweis: Aus den Voraussetzungen die Folgerung herleiten.
- Kontraposition: Aus der falschen Folgerung die falsche Voraussetzung ableiten.
- Widerspruch: Die Negation des Ziels annehmen und eine Unmöglichkeit herleiten.
- Gegenbeispiel: Eine Allaussage mit einem erlaubten Fall widerlegen.
- Induktion: Anfang und Schritt von $n$ zu $n + 1$ beweisen; eine Methode für eine spätere Lektion, kein Ersatz für einen dieser Schritte.

## Ein kleiner Arbeitsablauf

Formuliere Behauptung und Bereich genau. Löse Definitionen auf. Wähle eine Methode. Begründe jeden Übergang. Halte fest, was bewiesen ist. Für $\exists n \in  \mathbb{N} : n^2 = 9$ genügt $n = 3$ als Zeuge. Für $\forall n \in  \mathbb{N} : n^2 > n$ genügt $n = 1$ als Gegenbeispiel. Beides braucht keine lange Rechnung. Nutze die Behauptung nicht selbst zur Begründung eines Zwischenschritts: Das wäre ein Zirkelschluss.

## Beliebig bedeutet keine repräsentative Stichprobe

Zum Beweis von $\forall x\in\mathbb R\;(x+2>x)$ lies „Für jede reelle Zahl $x$ ist $x$ plus zwei größer als $x$“. Fixiere ein beliebiges reelles $x$. Addiere zu beiden Seiten von $2>0$ die Zahl $x$; daraus folgt $x+2>x+0=x$. Addition erhält die Ordnung; Addition von null ändert nichts. Kein Schritt verlangt Positivität, Ganzzahligkeit oder einen speziellen Wert von $x$. Das Argument erfasst daher jede reelle Eingabe.

Bei einer universellen Implikation nimmt man vorläufig die ganze Voraussetzung an und leitet die Folgerung her. Eingaben mit falscher Voraussetzung machen die Implikation bereits wahr. Das behauptet weder, dass jede Eingabe die Voraussetzung erfüllt, noch dass eine passende Eingabe existiert. In einer leeren Teilmenge kann kein Mitglied scheitern. Man darf auch unter einer vorläufigen Zugehörigkeitsannahme argumentieren und diese anschließend aufheben, ohne ein Mitglied zu behaupten. Die vollständigen Prüfungen stehen bei [Grundbereichen](../universal-statements-and-domains/) und [Gegenbeispielen](../counterexamples/).

<Exercise question="Ein Beweis über alle reellen Zahlen beginnt mit einer beliebigen positiven reellen Zahl und prüft danach sieben. Was ist damit gezeigt? Wie muss er mit einer wirklich nötigen Positivitätsannahme umgehen?">

Die Zahlenprobe erfasst nur sieben. Ein ansonsten allgemeines Argument unter Positivität erfasst höchstens positive reelle Zahlen, nicht null oder negative. Für die ursprüngliche Allaussage muss die Annahme vermieden oder durch begründete Null- und Negativfälle ergänzt werden. Alternativ kann man einen ausdrücklich eingeschränkten Satz formulieren und beweisen, darf ihn aber nicht als den ursprünglichen ausgeben. Das Wort beliebig hebt eine spätere Einschränkung nicht auf.

</Exercise>

## Von einer Definition zum Beweis

Für die Summe zweier gerader Zahlen nutze getrennte Zeugen: $a = 2r$ und $b = 2s$. Dann ist $a + b = 2(r+s)$, wobei $r + s$ ganzzahlig ist. Das entspricht genau der Definition von Geradheit. $a = 2r$ und $b = 2r$ würde versehentlich gleiche Eingaben voraussetzen. Auch ein kurzer Beweis braucht den Bereich und die Erklärung, warum die letzte Zeile das Ziel erreicht.
