Ana uses only red and Ben only blue. Each has a key, yet no key works for everyone. Add a green key both may use: now both requirements hold. Add two master keys: either can witness the shared claim. A shared witness is held fixed, not necessarily unique.

$$
\underbrace{\exists k\in K\;\forall p\in P\;H(p,k)}_{\text{S}}\ \Rightarrow\ \underbrace{\forall p\in P\;\exists k\in K\;H(p,k)}_{\text{T}}.
$$

Here $P,K$ are fixed people and key domains, and $H(p,k)$ means that $p$ can use $k$. To prove the implication, assume S and fix a key it supplies. Take any allowed person. The key works for that person because it works for all. Reuse it as that person’s witness. No distinctness of choices is required. Thus S implies T. The complete red–blue model refutes the converse.

Stronger means that shared success implies separate success. It does not mean opposite truth values in every situation. With green both are true; if someone has no usable key both are false. A finite complete permission table can establish these finite claims; a sample from an infinite domain cannot settle every case.

## All empty-domain cases

| People | Keys | Separate T | Shared S |
| --- | --- | --- | --- |
| empty | nonempty | true | true |
| nonempty | empty | false | false |
| empty | empty | true | false |

With no people, the universal-first form has no failing person. The shared form still needs a key: any existing key works vacuously, but if no key exists the form is false. With people but no keys, each person lacks a witness. The implication S to T remains valid in every case. A true premise supplies a key to reuse; a false premise makes the implication true.

For real comparisons, [quantifier order](../quantifier-order/) proves separate $y>x$ true and shared $y>x$ false. For the non-strict variant $y\ge x$, separate success follows even with $y=x$. Shared success still fails, but testing $x=y$ no longer defeats it: test $x=y+1$ instead.
