### Un recorrido compacto por el material

Empieza con <a href={lessonUrl("aussagen-und-aussageformen","es","analysis")+"#from-aussagen-und-aussageformen"}>enunciados y predicados</a>, <a href={lessonUrl("aussagen-und-aussageformen","es","analysis")+"#from-definitions-assumptions-results"}>definiciones</a>, <a href={lessonUrl("zahlenmengen","es","analysis")+"#from-equality-and-equations"}>igualdad</a>, <a href={lessonUrl("zahlenmengen","es","analysis")+"#from-order-comparisons"}>comparaciones de orden</a>. Conecta después <a href={lessonUrl("logische-verknuepfungen","es","analysis")+"#from-logische-verknuepfungen"}>conectivas lógicas</a>, <a href={lessonUrl("logical-negation","es","analysis")+"#from-logical-negation"}>negación</a>, <a href={lessonUrl("logische-verknuepfungen","es","analysis")+"#from-building-truth-tables"}>construcción de tablas de verdad</a> con <a href={lessonUrl("implikation-und-kontraposition","es","analysis")+"#from-material-implication-and-vacuity"}>implicación</a> y <a href={lessonUrl("biconditionals-and-equivalent-conditions","es","analysis")+"#from-biconditionals-and-equivalent-conditions"}>equivalencia</a>.

Lee <a href={lessonUrl("universal-statements-and-domains","es","analysis")+"#from-universal-statements-and-domains"}>enunciados universales</a>, <a href={lessonUrl("universal-statements-and-domains","es","analysis")+"#from-bound-variables-and-scope"}>alcance</a>, <a href={lessonUrl("universal-statements-and-domains","es","analysis")+"#from-existence-and-witnesses"}>existencia</a>, <a href={lessonUrl("quantifier-order","es","analysis")+"#from-quantifier-order"}>orden y dependencia</a> y <a href={lessonUrl("negating-nested-statements","es","analysis")+"#from-negating-quantified-statements-step-by-step"}>procedimiento de negación</a>. Para la <a href={lessonUrl("reading-sequence-convergence","es","analysis")+"#from-reading-sequence-convergence"}>aplicación a la convergencia</a>, estudia primero <a href={lessonUrl("real-sequences","es","analysis")+"#from-real-sequences"}>sucesiones</a> y <a href={lessonUrl("real-sequences","es","analysis")+"#from-absolute-value-and-distance"}>distancia absoluta</a>. Su <a href={lessonUrl("negating-sequence-convergence","es","analysis")+"#from-negating-sequence-convergence"}>deducción de su negación</a> separa fallo en objetivo fijo de <a href={lessonUrl("negating-sequence-convergence","es","analysis")+"#from-no-real-limit"}>no tener ningún límite real</a>.

Se conservan las aplicaciones de pósteres y hojas. Las tareas booleanas con leyes numeradas exigen deducciones algebraicas, no tablas de verdad como sustituto.

1. Distingue enunciados de frases con variables libres.
2. Precisa dominio y cuantificadores.
3. Identifica estructura y dirección de implicación.
4. Elige método de prueba; justifica pasos.
5. Usa solo reglas booleanas ya demostradas.
6. Distingue subexpresiones repetidas de salidas reutilizables de puertas físicas.

### Un problema combinado

Para enteros $n$, comprueba «$n^2$ par implica $4\mid n$». Paridad solo da $n$ par, no divisible por cuatro. El contraejemplo $n=2$ tiene cuadrado par $4$, pero no es divisible por $4$. Un teorema pertinente puede probar menos de lo pedido.
