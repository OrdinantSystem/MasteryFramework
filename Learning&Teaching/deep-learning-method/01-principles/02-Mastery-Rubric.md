# Mastery Rubric

Use six dimensions; each requires an **observable unassisted demonstration**, not a self-reported feeling.

| Dimension | Evidence task | Typical failure |
|---|---|---|
| Definitions | State accurately, interpret conditions, produce example/non-example | Missing quantifier or condition |
| Intuition | Explain meaning and motivation without losing precision | Nice analogy contradicts definition |
| Proof / justification | Construct a coherent argument using permitted facts | Gap, circular reasoning, wrong converse |
| Boundary testing | Construct counterexample; discuss necessity of hypotheses | Assumes statement works universally |
| Transfer / strategy selection | Solve an unfamiliar mixed problem without a named procedure | Only solves recognizable patterns |
| Delayed retention | Repeat explanation/application days or weeks later | Only short-term recognition |

## Evidence scale (per dimension)

- `0 — not demonstrated`: cannot yet perform the task.
- `1 — guided`: succeeds with substantial hints or example in sight.
- `2 — partially independent`: succeeds on routine cases, but gaps remain.
- `3 — independent`: accurate, justified, and unassisted on representative tasks.
- `4 — flexible`: succeeds on unfamiliar variations, explains boundaries, and can connect multiple ideas.

**Do not average scores into a deceptive single “mastery percentage.”** Keep a profile and evidence references. A dimension not assessed is `NA`, not zero.

## Provisional vs durable

Immediate independent performance = **provisional**. Delayed independent performance on a new task = stronger evidence of **durable** mastery. A course exam can contribute evidence but cannot substitute for coverage across dimensions.

## Proof correctness checklist

Every proof should clarify assumptions, definitions, intermediate claims, quantifiers, and conclusion. Test if a converse was silently assumed and if a counterexample refutes an overgeneralization.
