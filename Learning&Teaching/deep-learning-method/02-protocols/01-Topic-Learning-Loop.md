# Topic Learning Loop

**Use when:** beginning or extending a concept. **Input:** topic, target capability, time, level, trusted sources. **Output:** independent evidence + next review.

## Phase 0 — Baseline (3–10 min)

Agent asks 2–3 targeted questions or gives one short problem without teaching first. Record what is independently known. Unknown prerequisites become first targets.

## Phase 1 — Conceptual map (5–15 min)

Agent provides a deliberately partial map: key objects, definitions, dependency links, relationships, and uses. Learner completes edges, states plausible relationships, and flags confusion. The map is **provisional**, not proof.

## Phase 2 — Intuition → formalism (adaptive)

Begin with a motivating example or counterexample. Let learner predict or derive what should be true. State exact formal definition/theorem and examine why each assumption matters. One worked example is permitted if necessary; then fade help.

## Phase 3 — Independent practice (largest block)

A ladder of tasks: (1) recognize/non-example, (2) reconstruct, (3) routine application, (4) unfamiliar transfer, (5) generalization/proof. **Not every topic needs every level within one sitting.** Agent hides answers until attempted, uses [[02-protocols/02-Proof-Workshop]] for proof tasks, and records assistance level.

## Phase 4 — Challenge and repair

Agent offers adversarial variations: altered hypotheses, mistaken arguments, counterexamples, alternative approaches, combined concepts. For each mistake use [[02-protocols/04-Error-Diagnosis]]. Learner then retries a *different* example unassisted.

## Phase 5 — Exit ticket (5–10 min)

Without notes, learner writes:
1. Core definition/claim in precise words.
2. One explanation of *why* it holds, or proof sketch with justified transitions.
3. One task solved independently.
4. One misconception/boundary example.

If any of these fails, assign a targeted next action, not a generic reread.

## Phase 6 — Spacing and continuity

Create/update [[04-templates/01-Session-Note]], [[04-templates/02-Concept-Mastery-Card]], and review queue following [[02-protocols/03-Review-and-Retention]]. Mark which claims remain unverified.

## Adaptation rules

- Novice missing prerequisites → more examples and explanations.
- Routine problems easy, novel ones fail → more transfer and method selection.
- Correct answer, weak explanation → self-explanation and proof reconstruction.
- High confidence, poor accuracy → calibration and counterexamples.
- Fatigue or diminishing returns → stop or shorten, plan a later attempt.
