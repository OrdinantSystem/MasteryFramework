# Measurement and Experiments

## What we want to optimize

**Durable, independent, transferable understanding per sustainable study hour.** Avoid treating number of pages, study hours, or enthusiasm as direct proof of mastery.

## Core observables

| Measure | How to observe | Important caveat |
|---|---|---|
| Independent correctness | Unassisted, closed-notes tasks | Difficulty must be comparable |
| Proof rigor | Review of validity and completeness | Grading should follow explicit rubric |
| Transfer | Novel tasks, theorem not named | Distinguish novelty from impossible difficulty |
| Delayed retention | New tests days/weeks later | Need comparable coverage |
| Assistance dependence | Highest hint level and notes use | Hints vary in helpfulness |
| Calibration | Confidence predicted before test vs result | Not a substitute for correctness |
| Time / effort | Active minutes and fatigue | Time alone is not learning |

## Lightweight weekly dashboard

Record: topics attempted, unassisted tasks correct/total, proof-gap count, novel transfer successes/attempts, delayed checks passed/attempts, median hint level (if useful), active hours, highest-priority gaps. **Avoid a single opaque mastery score.**

## Small A/B comparison (optional)

1. Choose two comparable, unfamiliar topics, or alternate matched problem sets.
2. Set the same study time and an independently specified scoring rubric.
3. Use current method for one and a comparison approach for the other; alternate order when repeating.
4. Test immediately and again after 7–21 days with **new, equivalent tasks**.
5. Compare independent correctness, transfer, proof rigor, time, and fatigue.
6. Avoid sweeping conclusions from one comparison: baseline difficulty and topic differences matter.

## Decision rule for changes

State a hypothesis and observable success criterion **before** changing the protocol. Example: “Fewer early hints will increase H0 transfer successes after 7 days without raising dropout/frustration markedly.” Reassess after several sessions; keep, revise, or revert.

## Research caution

Learning efficiency = change in independent performance / invested time is a **useful working idea**, not a universally standardized metric. Scores from different topics are not directly comparable without equating task difficulty.
