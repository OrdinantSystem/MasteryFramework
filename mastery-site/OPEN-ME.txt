MASTERY FRAMEWORK — REACT STATIC EDITION

Open dist/index.html in your browser. In the ZIP, open Mastery/index.html.
Keep the assets and archive folders beside the HTML files.
No server, installation, internet connection, or AI key is required to read it.

The site now uses shared React teaching components and typed lesson content.
Read continuously, work through the examples, then pause at the questions.
Reference answers stay closed until requested. Optional attempts save in this
browser when local storage is available; they are not sent to an AI service.
Use the light/dark button to switch themes. Yellow and amber are excluded.

The original documents and transcripts remain in the Source library.
Earlier editions are preserved under archive/.
The mathematics examples demonstrate the format, not complete courses.

EDITING THE SOURCE
Node.js 22+ and npm are required only for editing/building:
  npm ci
  npm run dev
  npm run build
  npm run package

The ZIP includes the editable project under Source/.
Read README.md and DESIGN-SYSTEM.md before adding a lesson or component.
src/content/ holds lessons; src/components/ holds reusable teaching patterns;
design-tokens.json owns the color, type, spacing, and layout scales.
